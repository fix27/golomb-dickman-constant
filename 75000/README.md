# Постоянная Голомба–Дикмана: 75 000 знаков с интервальным сертификатом

$$\lambda=\int_0^\infty e^{-u-E_1(u)}\,du
=0.624329988543550870992936383100837244\ldots$$

Сертификат [`golomb_dickman_75000_certified.txt`](golomb_dickman_75000_certified.txt)
содержит целые $\Lambda_-<\Lambda_+$ и масштаб $S=249341$ такие, что

$$\left\lfloor 10^{75000}\Lambda_-/2^S\right\rfloor
=\left\lfloor 10^{75000}\Lambda_+/2^S\right\rfloor .$$

Значит, первые **75 000** десятичных знаков (усечение, не округление)
выведены из интервала точной целочисленной арифметикой. Ширина интервала —
$5.8205594787\times10^{-75043}$, то есть сверх 75 000 знаков остаётся
$42.2350$ гарантированных знака.

Это **новый результат**; сертификаты на 50 000 и 40 000 знаков сохранены
без изменений как предыдущие (`../50000/`, `../40000/` и `../40000-v2/`).

## Как проверить

```bash
cd ..   # корень репозитория

python verification/verify_certificate.py \
    --cert 75000/golomb_dickman_75000_certified.txt \
    --digits-file golomb_dickman_75000_digits.txt \
    --sha256-manifest 75000/SHA256SUMS.txt \
    --bfile submission/b084945.txt \
    --sha256 b084945.txt=05584c9d3f0afccbfb9a1d8c8f28177a33a30be3ec880dc6ffe481a136b19241

python verification/audit_chunks.py \
    --ckpt 75000/gd_rigorous_ckpt_75000 \
    --cert 75000/golomb_dickman_75000_certified.txt
```

Оба скрипта используют только стандартную библиотеку Python и точную
целочисленную арифметику; при расхождении завершаются ненулевым кодом.
Для полного Arb-аудита (часы работы) нужен `python-flint` и отдельный запуск
`verification/verify_all_arb.py`.

## Воспроизведение расчёта (CLI v27)

Нужны Python 3.11+, [`python-flint`](https://github.com/flintlib/python-flint)
(Arb) и [`mpmath`](https://mpmath.org/) для `crosscheck`:

```bash
python -m pip install python-flint mpmath
python golomb_dickman_27.py test
python golomb_dickman_27.py smoke
python golomb_dickman_27.py certify --digits 75000
python golomb_dickman_27.py crosscheck --digits 200
python golomb_dickman_27.py boundary-test
```

Результат получен именно CLI v27; план прогона — `gd-checkpoint-v13` из
`meta_v13.json`.

- `test` — самопроверка окружения и точные рациональные проверки леммы 7;
- `smoke` — сквозной прогон на 60 знаках;
- `certify` — полный сертификат; значение `--digits` по умолчанию — 40 000,
  поэтому для текущего результата нужен `--digits 75000`. Пишет
  `golomb_dickman_<D>_certified.txt` в текущий каталог и чекпоинты в
  `gd_rigorous_ckpt_<D>/`;
- `crosscheck` — независимые сверки через `mpmath`/`mpmath.iv`, цепные дроби,
  форсированные ветви, альтернативный шаг и лестницу точности;
- `boundary-test` — граничные тесты леммы 7.

> **Не запускайте `certify` внутри `40000/`, `40000-v2/` или `50000/`.**
> Каталог чекпоинтов по умолчанию — `gd_rigorous_ckpt_<D>/` в текущем
> каталоге, то есть тот же, где лежат опубликованные куски (1 209 в `40000/`,
> 3 076 в `50000/`), поэтому они будут перезаписаны кусками другого размера.
> Для нового счёта используйте пустой каталог или явный `--ckpt`; опубликованные
> каталоги считайте read-only. `--resume` — только аудиторский режим: он
> доверяет готовым чекпоинтам и **не выдаёт сертификат**; по умолчанию каждый
> кусок пересчитывается в Arb. Полный прогон занимает часы CPU.

### База доверия

1. корректность интервальной арифметики Arb (`python-flint`);
2. теорема о трапециях для аналитических функций в полосе (Trefethen &
   Weideman, *SIAM Review* 56 (2014), Thm 5.1);
3. классическая теорема Стилтьеса о двусторонних оценках подходящими дробями;
4. леммы из docstring вычислителя (§1–§7);
5. точная целочисленная арифметика Python.

Это не проверка в proof assistant; каталоги `coq/` и `lean/` содержат лишь
экспериментальную формализацию отдельных лемм.

## Оговорки

- **Полный Arb-аудит не выполнялся.** Пересчитаны и проверены только первые
  20 чанков (2 000 узлов из 476 648); все они contained. По измеренной
  скорости полный прогон занимает около 9 ч на 4 потоках (≈3 ч на 11),
  поэтому в рамках лимита на процесс не запускался. До его завершения
  сертификат опирается на исходный прогон продюсера.
- `verification/audit_chunks.py` и `verification/verify_all_arb.py` пока
  ищут только `meta_v12.json`, а здесь лежит `meta_v13.json`. Для Arb-выборки
  применялось временное зеркало вне репозитория с преобразованным
  `meta_v12.json`; сами чекпоинты и план не менялись.
- черновик b-file для 75 000 знаков подготовлен в
  `submission/b084945.txt` с письмом `submission/oeis-bfile-75000.eml`,
  но **не отправлен**; в OEIS по-прежнему b-file `n = 0..101`. Проверка
  102-значного префикса OEIS A084945 входит в `verify_certificate.py`: первые
  102 знака совпадают с опубликованным префиксом A084945.
- Независимая квадратура на 300 знаков дала 320 совпадающих знаков;
  запрос на 1 000 знаков превысил лимит времени и был остановлен. Это
  численная проверка, а не доказательство.
- Простые усечения после длины 2508 проверены выборочно (2526, 9867, 17257 —
  составные), не исчерпывающе.
- Это расширение результата, а не заявка на мировой рекорд; о нормальности
  $\lambda$ ничего не утверждается.
